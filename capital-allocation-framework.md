# Optimal Capital Allocation under Stochastic Opportunity Arrival

**A self-contained framework for deploying a fixed capital endowment across a bursty stream of
scored, size-quantified opportunities with stochastic lock durations.**

The document is written in the language of stochastic control, queueing theory, and empirical
processes. It deliberately makes **no reference to any specific market microstructure beyond the
minimal, neutral description of the payoff generator in §2**: a venue whose quoted price is a
deterministic function of a scalar reserve (a "constant-product" schedule), a commitment that
moves that reserve, a subsequent independent transaction that moves it again, and a reversal of
the commitment. The reader requires only graduate-level probability and optimisation; the domain
specifics are confined to §2 and are treated as an empirical input.

---

## 1. Scope, notation, and primitives

### 1.1 Time

* Time is discrete and indexed by a slot counter $\tau \in \mathbb{Z}_{\ge 0}$, with a fixed slot
  width $\Delta t \approx 400\,\text{ms}$.
* The horizon is $H$ slots ($H = 216{,}000 \approx 24\,\text{h}$).
* All decisions are **adapted**: an action at slot $\tau$ may depend only on the filtration
  $\mathcal{F}_\tau$ generated by observations up to and including slot $\tau$. No decision may
  anticipate a future arrival, a future counterparty transaction, or a future price movement.

### 1.2 Notation

| Symbol | Meaning |
|---|---|
| $C_0$ | Initial capital endowment ($C_0 = 0.5$ units). |
| $C(\tau)$ | **Free (uncommitted) capital** at slot $\tau$. |
| $B(\tau)$ | **Committed capital** at slot $\tau$: $B(\tau) = \sum_{i \in A(\tau)} \kappa_i$. |
| $W(\tau)$ | **Book wealth** $= C(\tau) + B(\tau)$. |
| $A(\tau)$ | Set of active (committed, not yet unwound) events at slot $\tau$. |
| $e_i$ | The $i$-th opportunity in arrival order. |
| $\tau_i$ | Arrival slot of $e_i$. |
| $\kappa_i = \kappa(e_i)$ | Prescribed commitment size of $e_i$ (units of the base asset). |
| $\pi_i = \pi(e_i)$ | Prescribed available surplus of $e_i$ at commitment $\kappa_i$. |
| $\rho_i = \rho(e_i)$ | Return on commitment, $\rho_i = \pi_i / \kappa_i$. |
| $\nu_i = \nu(e_i)$ | Number of prior opportunities on the same pool within 300 slots. |
| $\psi_i = \psi(e_i)$ | Pool fee rate in basis points ($\psi_i \in [0,125]$). |
| $\sigma_i = \sigma(e_i)$ | Model score in $[0,1]$ (predictive confidence). |
| $L_i$ | Random lock duration (slots), $L_i \in \{1,\dots,8\}$. |
| $Z_i$ | Indicator that a counterparty arrives within the bounded window ($Z_i = 1$). |
| $\ell_i$ | Fractional loss if no counterparty arrives ($Z_i = 0$). |
| $q_i$ | $\Pr(Z_i = 1 \mid \mathcal{F}_{\tau_i})$, counterparty-arrival probability. |
| $\delta$ | Lookback window (slots). |
| $F_\Delta, F_\kappa, F_\rho, F_L$ | Distribution functions of inter-arrival gap, commitment size, return, lock duration. |

### 1.3 Payoff generator (minimal description)

Each opportunity $e$ is fully described ex-ante by a tuple

$$
e \;=\; (\tau,\ \kappa,\ \rho,\ \nu,\ \psi,\ \sigma,\ \text{pool},\ \text{venue},\ \lambda).
$$

The number $\kappa(e)$ is the **optimal commitment size** for $e$: a concave *profit schedule*
$g_e : [0, \kappa(e)] \to \mathbb{R}_{\ge 0}$ with $g_e(0) = 0$, $g_e(\kappa(e)) = \pi(e)$,
$g_e$ non-decreasing, and $\kappa(e)$ a maximiser of $g_e$. In the **binary model** (the primary
object of §5) the agent either commits the full $\kappa(e)$ or commits nothing; the partial
schedule $g_e$ is used only by the allocation rule in §7.3. The dataset supplies only the
endpoint values $(\kappa(e), \pi(e))$; the interior of $g_e$ is recovered from the constant-product
geometry (see Remark 2.1).

## 2. Empirical input: the event stream

The input is a finite sample of $n = 61$ scored opportunities (a strict subsample of a larger
stream). Each carries the schema of §1.3. The following **empirical summaries** are the only
aggregate inputs the framework assumes:

| Quantity | Value |
|---|---|
| $n$ | 61 |
| $\bar\kappa$, median $\kappa$, $q_{0.95}(\kappa)$ | $0.023,\ 0.004,\ 0.12$ (units) |
| $\bar\rho$, median $\rho$, $q_{0.95}(\rho)$ | $0.034,\ 0.022,\ 0.082$ |
| $\bar\Delta$ (inter-arrival, slots) | 18 ($\approx 7.2$ s), median 4, bursty (same-slot batches) |
| Concentration | top 3 pools $\to$ 41% of events |
| Latency tier | all $\lambda = \text{"visible"}$ ($< 4$ slots) |

**Remark 2.1 (what the data are).** $\kappa(e), \pi(e), \rho(e), \sigma(e)$ are **ex-ante
estimates** produced by a scoring pipeline (a golden-section search on the constant-product
schedule plus a gradient-boosted classifier). They are *predictions*, not realised outcomes: the
realised return of a commitment is random, equal to $\rho(e)$ only when a counterparty arrives
($Z = 1$), and to a negative quantity $-\ell(e)$ otherwise. The framework therefore treats the
scored attributes as *sufficient statistics* feeding a distributional model, never as certainties.
Where the interior of $g_e$ is needed, the standard CPMM solution is

$$
g_e(x) \;=\; \rho(e)\, x \left(2 - \frac{x}{\kappa(e)}\right), \qquad x \in [0, \kappa(e)],
$$

which is concave with $g_e(0)=0$, $g_e(\kappa)=\pi$, marginal return $g_e'(0) = 2\rho$ and
$g_e'(\kappa) = 0$; any other concave surrogate may be substituted without changing the framework.

## 3. Wealth dynamics and the capital constraint

### 3.1 Accounting identities

Book wealth decomposes as

$$
W(\tau) \;=\; C(\tau) + B(\tau), \qquad B(\tau) = \sum_{i \in A(\tau)} \kappa_i . \tag{3.1}
$$

* **Commitment** of $e$ at slot $\tau$ (with size $x \in [0,\kappa(e)]$):

$$
C(\tau^+) = C(\tau^-) - x, \qquad B(\tau^+) = B(\tau^-) + x, \qquad W \text{ unchanged}.
$$

* **Unwind** of $e$ at slot $\tau + L + 1$ (the commitment is reversed one slot after the
  counterparty slot; if no counterparty arrives by slot $\tau + L_{\max}$, the position is closed
  at slot $\tau + L_{\max} + 1$ with an adverse-movement loss):

$$
C \leftarrow C + x \big(1 + R(e)\big), \qquad B \leftarrow B - x,
\qquad R(e) =
\begin{cases}
\rho(e) - \psi(e)\cdot 10^{-4}, & Z = 1, \\[2pt]
-\ell(e), & Z = 0,
\end{cases} \tag{3.2}
$$

where $\psi(e)\cdot 10^{-4}$ converts basis points to a fractional fee and $\ell(e) \ge 0$ is the
expected fractional adverse-movement loss over the lock window. If $\rho(e)$ is already reported
net of fee, set $\psi \equiv 0$ in (3.2); the conservative choice is to subtract the fee.

The **expected net return per unit committed** is therefore

$$
\mu(e) \;:=\; \mathbb{E}[R(e) \mid \mathcal{F}_{\tau}]
\;=\; q(e)\big(\rho(e) - \psi(e)10^{-4}\big) \;-\; \big(1 - q(e)\big)\,\ell(e). \tag{3.3}
$$

Equation (3.3) is the single most important correction in the framework: the scored $\rho(e)$ is a
*conditional-on-success* figure, and the decision rule must be driven by $\mu(e)$, not $\rho(e)$.

### 3.2 The hard constraint (and a necessary clarification)

The constraint as stated,

$$
C(\tau) + \sum_{i \in A(\tau)} \kappa_i \;\le\; C_0 \qquad \forall \tau, \tag{3.4}
$$

is **incompatible with capital growth**: under (3.2) a successful unwind increases $W$ (hence
$C + B$) above $C_0$, and §7.4 explicitly contemplates $C(\tau)$ exceeding $T_1 = C_0$, $T_2 =
2C_0$, $T_3 = 5C_0$. The constraint is therefore read as a pair of coupled conditions:

1. **Feasibility** — one may never commit more than the free capital on hand:

$$
\kappa(e_i) \;\le\; C(\tau_i^-), \quad\text{i.e.}\quad C(\tau) \ge 0 \ \ \forall\tau . \tag{3.5}
$$

2. **Risk (exposure) cap** — the total capital *at risk concurrently* never exceeds the initial
   endowment:

$$
B(\tau) \;=\; \sum_{i \in A(\tau)} \kappa_i \;\le\; C_0 \qquad \forall \tau . \tag{3.6}
$$

Under (3.5)–(3.6), $W(\tau) = C_0 + \Pi(\tau)$, where $\Pi(\tau)$ is cumulative realised net
profit, so wealth starts at $C_0$ and is free to grow (and, via downside $\ell$, to shrink). The
"hard capital constraint" is thus (3.6): the concurrent exposure is capped at $C_0$, while free
capital $C(\tau)$ grows with profit. Equation (3.4) remains valid at the single moment of full
deployment with zero profit ($C=0$, $B=C_0$).

Finally, the **lookback restriction** on $A(\tau)$:

$$
A(\tau) \;\subseteq\; \{\, e_i : \tau_i \in [\tau-\delta,\ \tau] \,\} \tag{3.7}
$$

expresses that every commitment has a bounded lifetime. Since $\operatorname{supp}(L) \subseteq
[1,8]$, any commitment older than 8 slots has already resolved, so the natural calibration is

$$
\delta \;=\; \sup\operatorname{supp}(L) + \varepsilon \;=\; 8 + \varepsilon, \qquad \varepsilon \ge 0, \tag{3.8}
$$

with $\varepsilon$ a latency/deferral buffer (§7.2). With $\delta = 8$ the restriction (3.7) is
non-binding relative to the lock bound.

## 4. State representation

We adopt a **Markov state** that is sufficient for decision-making, i.e. such that the value of
any future policy is a function of the current state alone. At slot $\tau$:

$$
S(\tau) \;=\; \big(\; C(\tau),\ Q(\tau),\ \mathcal{P}(\tau),\ m(\tau)\; \big), \tag{4.1}
$$

* **$C(\tau)$** — free capital (scalar). Together with the active set it determines feasibility.

* **$Q(\tau)$** — a FIFO queue of *pending* (arrived but not yet decided) opportunities whose
  arrival lies within the lookback: $Q(\tau) = \{(e, \tau_i, d_i)\}$ with decision deadline
  $d_i = \tau_i + \delta$. The queue is the carrier of the deferral option: an event need not be
  accepted or rejected at $\tau_i$; it may be held until $d_i$ (after which it expires).

* **$\mathcal{P}(\tau)$** — per-pool sufficient statistics. For each pool $\nu$:

$$
\mathcal{P}_\nu(\tau) = \big(\; m_\nu(\tau),\ \hat\mu_\nu(\tau),\ \hat\kappa_\nu(\tau),\
n_\nu^{300}(\tau)\; \big),
$$

where $m_\nu$ = number of *active* commitments on $\nu$, $\hat\mu_\nu$ = running estimate of
expected net return on $\nu$ (shrinkage-adjusted, §8.3), $\hat\kappa_\nu$ = running estimate of
the commitment-size scale on $\nu$, and $n_\nu^{300}$ = count of opportunities on $\nu$ in the
last 300 slots (this equals the event attribute $\nu(e)$ at arrival).

* **$m(\tau)$** — the multiset of active commitments $\{(e_j, \kappa_j, \tau_j, L_j)\}$; its
  aggregate size is $B(\tau)$, and its per-pool counts feed $\mathcal{P}$. (When $L_j$ is random,
  $m$ stores the *residual* lock distribution of each active job, updated as the window elapses.)

The state is Markov because (i) the payoff generator in §1.3 is a function of the scored tuple
alone; (ii) future arrivals depend only on the pool statistics (through the bursty arrival model
of §6) and not on the history beyond $\mathcal{P}$; and (iii) active commitments affect the future
only through the capital they bind, which is captured by $m$. The empirical arrival model is
estimated once (§8) and held fixed, so it need not be part of the *per-slot* state.

## 5. Bellman optimality condition

### 5.1 Decision epochs and the semi-Markov structure

Rewards are realised $\tau + L + 1$ slots *after* a decision, so the problem is a **semi-Markov
decision process (SMDP)** over decision epochs. We take a decision epoch to be any slot $\tau$ at
which the FIFO queue is non-empty ($Q(\tau) \ne \varnothing$); the policy acts on the head event
$e$. Three actions are available:

$$
a \in \{\ \text{commit},\ \text{reject},\ \text{defer}\ \},
$$

with "defer" legal only while $\tau < d$ (the event's deadline) and "commit" legal only while
$\kappa(e) \le C(\tau^-)$ and $B(\tau^-) + \kappa(e) \le C_0$. "Commit" here means committing the
full $\kappa(e)$ (binary model); partial sizing is deferred to the allocation rule of §7.3.

### 5.2 Finite-horizon value function

Let $V_h(S)$ be the optimal expected terminal wealth with $h = H - \tau$ slots remaining, from
state $S$. The terminal condition is

$$
V_0(S) \;=\; W(\tau) \;=\; C(\tau) + B(\tau). \tag{5.1}
$$

At a decision epoch, the Bellman equation is

$$
V_h(S) \;=\; \max_{a} \Big\{
\underbrace{\mathbb{E}\big[ V_{h-1}(S^{\text{rej}}') \big]}_{a=\text{reject}},\;
\underbrace{\mathbb{E}_{L,Z,\ \text{arrivals}}\big[\; \kappa(e)\,R(e) \;+\; V_{h-1}(S^{\text{com}}') \;\big]}_{a=\text{commit}},\;
\underbrace{\mathbb{E}\big[ V_{h-1}(S^{\text{def}}') \big]}_{a=\text{defer}}
\Big\}, \tag{5.2}
$$

where:

* $S^{\text{rej}}'$ is the state after $e$ is discarded and one slot elapses (active jobs age by
  one, resolved jobs release capital + return, new arrivals enter $Q$);
* $S^{\text{com}}'$ is the state after $e$ is committed — $C \leftarrow C - \kappa(e)$,
  $B \leftarrow B + \kappa(e)$ — followed by one slot of evolution; the reward
  $\kappa(e) R(e)$ is realised $\tau + L + 1$ slots later and is therefore embedded in the
  *future* terms $V_{h-L}(S^{\text{com}}')$ via (5.1), while the expectation over $(L, Z, \text{arrivals})$
  averages the random lock, the counterparty indicator, and the intervening stream;
* $S^{\text{def}}'$ is the state after one slot with $e$ still at (or re-inserted at) the head of
  $Q$ (its deadline $d$ unchanged).

**Remark 5.1 (binary form at arrival).** If deferral is forbidden and decisions are made exactly
at $\tau_i$, (5.2) reduces to the two-action form stated in the brief:

$$
V(S) \;=\; \max_{a\in\{0,1\}}\Big[\;
a\,\big(\,\pi(e)\;+\;\mathbb{E}[V(S'_{\text{commit}})]\,\big)
\;+\;(1-a)\,\mathbb{E}[V(S'_{\text{reject}})]\;\Big], \tag{5.3}
$$

with $S'_{\text{commit}}$ the stochastic post-state after the lock resolves.

### 5.3 Infinite-horizon discounted form

For deriving stationary threshold policies it is convenient to discount wealth at rate $r \ge 0$
per slot ($\gamma = e^{-r\Delta t}$, or $\gamma = 1$ for the pure-accumulation limit). The
stationary value satisfies the **Bellman optimality equation**

$$
V(S) \;=\; \max_{a \in \{\text{com},\text{rej},\text{def}\}}
\mathbb{E}\Big[\, u(a,e)\, \gamma^{\Delta'}\, + \, \gamma^{\Delta'}\, V(S')\,\Big], \tag{5.4}
$$

where $u(\text{com}, e) = \kappa(e) R(e)$, $u(\text{rej},e)=u(\text{def},e)=0$, and $\Delta'$ is
the (random) number of slots to the next decision epoch. Under a mild "geometric forgetting"
condition on the arrival and lock distributions, $V$ is the unique solution of (5.4) in the space
of bounded, measurable functions of $S$.

**Intractability.** The full DP is computationally intractable: the state includes a queue of
unbounded length, the lock duration is stochastic and reward-realisation is delayed, the arrival
process is bursty (not Poisson, hence not memoryless), and $(L,Z,\text{arrivals})$ are jointly
distributed. This motivates the *structural* results and the *approximate* policy of §6–§7, which
replace the value function with (i) a queueing-theoretic feasibility bound and (ii) a
threshold/water-filling rule whose free parameters are calibrated by the empirical estimates of
§8.

### 5.4 Monotonicity (a structural lemma)

Let $V$ be concave and non-decreasing in $C$ (true for the linear terminal payoff under
concavity-preserving transitions). Then:

* **(i) Value of capital is decreasing in scarcity.** The marginal value
  $\partial V / \partial C$ is non-increasing, so the opportunity cost of binding a unit of
  capital for $L$ slots is *higher* when $C$ is small. Hence the acceptance threshold should
  *rise* as $C \to 0$ (near-ruin) and *fall* as $C \to \infty$; this is exactly the dynamic-tier
  structure of §7.4.
* **(ii) A one-shot reserve price exists.** For a single opportunity with attributes
  $(\kappa,\rho,\nu,\sigma)$, there is a scalar $\theta^\ast(\kappa,\nu,\sigma,C)$ such that
  commit is optimal iff $\mu(e) \ge \theta^\ast$; this is the justification for the threshold
  policy of §7.1 (with $\mu$ the expected net return of (3.3), not the raw $\rho$).

## 6. Queueing-theoretic analysis and opportunity cost

### 6.1 The system as a renewable-resource queue

Treat the capital budget as a single divisible "server" of capacity $C_0$:

* **Arrivals** form a batch process: opportunities arrive in batches at slot boundaries, with
  batch size $\ge 1$ and inter-batch gaps drawn from a general distribution $F_\Delta$ (empirically
  with an atom at 0 gaps, i.e. same-slot multiplicity). This is a $G^X$ (general, batch) arrival
  stream, *not* Poisson.
* **Service** of an admitted job $e$ consists of holding $\kappa(e)$ units of the resource for a
  random "service time" $L \in [1,8]$, then returning $\kappa(e)(1+R(e))$.
* **Admission control** chooses which jobs enter subject to the knapsack constraint
  $\sum_{i \in A(\tau)} \kappa_i \le C_0$.

This is an *admission-controlled, batch-arrival, divisible-resource queue* — the natural
generalisation of $M/G/1$ in which the "server" is a continuous budget and service demand
$\kappa(e)$ is heterogeneous.

### 6.2 Little's law and the load condition

Let $\lambda_a$ be the long-run rate of **admitted** jobs (jobs/slot). Then, at stationarity,

$$
\mathbb{E}[\,|A|\,] = \lambda_a\, \mathbb{E}[L], \qquad
\mathbb{E}[B] = \lambda_a\, \mathbb{E}[\kappa]\, \mathbb{E}[L], \tag{6.1}
$$

where $\mathbb{E}[\kappa]$ is the mean admitted commitment size. The exposure cap (3.6) forces
$\mathbb{E}[B] \le C_0$, giving the **load condition**

$$
\varrho \;:=\; \frac{\lambda_a\, \mathbb{E}[\kappa]\, \mathbb{E}[L]}{C_0} \;\le\; 1 . \tag{6.2}
$$

Any admissible policy must keep $\varrho \le 1$ on average, which bounds the sustainable admission
rate $\lambda_a \le C_0 / (\mathbb{E}[\kappa]\,\mathbb{E}[L])$. Because $\mathbb{E}[\kappa]$ is
heavily right-skewed (p95/median $\approx 30\times$), the *admitted* $\mathbb{E}[\kappa]$ can be
shaped downward by capping per-event size — the first lever available to the policy.

### 6.3 Busy and idle periods

A **busy period** is a maximal interval $[\tau_1,\tau_2]$ with $B(\tau) > 0$; an **idle period**
is one with $B(\tau) = 0$. In a busy period the budget may be *partially* deployed (fractional
utilisation), so the process is a batch analogue of a server with variable occupancy. The relevant
quantities for the policy are

* **Fractional utilisation** $u(\tau) = B(\tau)/C_0 \in [0,1]$;
* **Expected busy-period capital-time cost** of a new commitment $\kappa$:
  $\kappa \cdot \mathbb{E}[L \mid \text{commit}]$, the expected capital-seconds (capital-slots)
  it consumes.

### 6.4 Opportunity cost and the break-even threshold

Committing $\kappa$ for $L$ slots forgoes the returns that $\kappa$ could have earned on the
*next-best* opportunity arriving in the meantime. With $\mathbb{E}[\rho^\ast]$ the expected return
of the best available alternative and $\mathbb{E}[\Delta]$ the expected inter-arrival time, the
**capital rental rate** (expected return per unit per slot) is

$$
c_{\text{opp}} \;=\; \frac{\mathbb{E}[\rho^\ast]}{\mathbb{E}[\Delta]}. \tag{6.3}
$$

The opportunity cost of a commitment of size $\kappa$ and duration $L$ is

$$
\Omega(\kappa, L) \;=\; \kappa \cdot c_{\text{opp}} \cdot \mathbb{E}[L]. \tag{6.4}
$$

A commitment is value-positive in expectation iff its expected net gain exceeds its opportunity
cost,

$$
\kappa\,\mu(e) \;\ge\; \kappa\, c_{\text{opp}}\,\mathbb{E}[L]
\;\;\Longleftrightarrow\;\;
q\big(\rho - \psi10^{-4}\big) - (1-q)\ell \;\ge\; c_{\text{opp}}\,\mathbb{E}[L], \tag{6.5}
$$

yielding the **break-even return threshold**

$$
\theta_{\text{be}} \;=\;
\frac{c_{\text{opp}}\,\mathbb{E}[L] \;+\; (1-q)\,\ell}{q}. \tag{6.6}
$$

**Concentration tension (§2 of the brief).** Full commitment $C_0$ into one event earns at most
$C_0\rho(e)$, but locks the whole budget for $\mathbb{E}[L]$ slots, forgoing
$\sum_{j : \tau_j \in [\tau, \tau+\mathbb{E}[L]]} \rho(e_j)\kappa(e_j)/C_0$ in alternative
returns. The break-even for full commitment,

$$
\rho(e)\,\mathbb{E}[L] \;\ge\; \frac{1}{C_0}\sum_{j} \rho(e_j)\,\kappa(e_j), \tag{6.7}
$$

is the special case of (6.5) with $q=1$, $\ell=0$, and the sum replacing $c_{\text{opp}}\mathbb{E}[L]$. A
policy that always commits fully fails (6.7) precisely when the stream is bursty: the burst
guarantees that the intervening sum is large.

## 7. Approximate policy

The exact DP of §5 is intractable; we specify a tractable policy with three components: a
**threshold gate**, a **water-filling allocation rule**, and **capital-tier dynamics**.

### 7.1 Threshold gate

The decision score for opportunity $e$ at free capital $C$ is the expected net return penalised
for (i) pool concentration and (ii) model uncertainty:

$$
s(e) \;=\;
q(e)\big(\rho(e) - \psi(e)10^{-4}\big) - \big(1-q(e)\big)\ell(e)
\;-\; \beta\,\nu(e)\,(1 - \sigma(e))
\;-\; \tfrac{\kappa(e)}{C_0}\cdot \eta. \tag{7.1}
$$

Term-by-term:

* $q\big(\rho-\psi10^{-4}\big)-(1-q)\ell$ — expected net return $\mu(e)$ (3.3).
* $\beta\,\nu(e)\,(1-\sigma(e))$ — a **concentration/uncertainty penalty**. $\nu(e)$ counts prior
  hits on the pool, a proxy for crowding and for the diminishing marginal information content of a
  repeated signal on the same pool; $(1-\sigma(e))$ up-weights the penalty when the model is
  unconfident. $\beta \ge 0$ is calibrated in §8.
* $\tfrac{\kappa(e)}{C_0}\eta$ — a **size (exposure) penalty**: larger commitments consume a larger
  fraction of the budget for $L$ slots; $\eta$ folds the opportunity-cost term
  $c_{\text{opp}}\mathbb{E}[L]$ into a per-unit-of-$C_0$ charge.

The gate is a threshold in the capital-adjusted score:

$$
g(e) \;:=\; \mathbf{1}\!\big\{\, s(e) \;\ge\; \theta(C) \,\big\}, \tag{7.2}
$$

with a capital-dependent threshold $\theta(C)$ that *decreases* as capital grows (Lemma 5.4(i)):

$$
\theta(C) \;=\; \theta_\infty + (\theta_0 - \theta_\infty)\, e^{-C/C_0}, \qquad \theta_0 > \theta_\infty \ge 0. \tag{7.3}
$$

When $C$ is near zero (near the liquidity floor), $\theta \approx \theta_0$: only the best
opportunities clear. As $C \to \infty$, $\theta \to \theta_\infty = c_{\text{opp}}\mathbb{E}[L]$
(the pure opportunity-cost floor). This is the mathematical resolution of tension §1
(commitment size vs. opportunity cost) and §4 (sparse-data robustness): robustness is obtained by
*shrinking* scores toward the threshold rather than point-estimating $\rho$.

### 7.2 Deferral within the lookback window

Because arrivals are bursty, a *defer* action is valuable: when several opportunities arrive in
the same slot, the policy may hold low-priority ones until their deadline $d_i = \tau_i + \delta$
in case a strictly better opportunity arrives (and to let active capital free up). Formally, at
each decision epoch the policy:

1. resolves active jobs whose lock has elapsed (§9);
2. removes from $Q$ any event with $\tau > d$ (expired);
3. evaluates the head $e$: if $g(e) = 1$ and feasible, **commit**; if $g(e)=0$ but
   $\tau < d_i$ **and** $s(e) \ge \theta(C) - \Delta_{\text{def}}$ (within a deferral band), keep
   $e$ in the queue (defer); otherwise **reject**.

The deferral band $\Delta_{\text{def}} \ge 0$ and $\delta$ are calibrated so that $\delta \ge
\sup\operatorname{supp}(L)$ (3.8); a practical choice is $\delta = 8$ and $\Delta_{\text{def}} = 0$
(pure threshold, no deferral) as the baseline, enabling deferral only after §9 shows it reduces
opportunity cost on bursty days.

### 7.3 Allocation rule (water-filling)

Given a set $\mathcal{E}$ of *accepted* events (those passing (7.2) and sharing the current
feasible budget), the total committed capital is allocated by equalising marginal returns across
the events, subject to the exposure cap. Using the quadratic schedule of Remark 2.1, the marginal
return of event $e$ at commitment $x$ is $g_e'(x) = 2\rho(e)(1 - x/\kappa(e))$. The allocation
$x_e^\ast$ solves

$$
\max_{x_e \in [0,\kappa(e)]} \sum_{e \in \mathcal{E}} g_e(x_e)
\quad\text{s.t.}\quad \sum_{e\in\mathcal{E}} x_e \le \min\!\big(C(\tau),\; C_0 - B(\tau)\big), \tag{7.4}
$$

whose solution is the **water-filling** rule

$$
x_e^\ast \;=\; \kappa(e)\Big(1 - \tfrac{\lambda}{2\rho(e)}\Big)_+, \qquad
\lambda \;=\; \frac{2\,\big(\sum_{e} \kappa(e) - \bar x\big)}{\sum_{e} \kappa(e)/\rho(e)}, \tag{7.5}
$$

with $\bar x = \min(C, C_0 - B)$ and $(\cdot)_+ = \max(\cdot,0)$. Two observations:

* The marginal return $g_e'(0)=2\rho(e)$ *exceeds* the average return $\rho(e)$, so under a tight
  budget it is optimal to **partially** commit to several high-$\rho$ events rather than fully to
  one — a formalisation of diversification (tension §2).
* In the binary limit (budget $\ge \sum\kappa$), (7.4) allocates $x_e = \kappa(e)$ for all
  accepted $e$, recovering the full-commitment model of §5.

### 7.4 Dynamic capital tiers

As free capital crosses the tiers $T_1 = C_0$, $T_2 = 2C_0$, $T_3 = 5C_0$, the policy transitions
from **proportional** to **absolute** sizing (tension §3):

| Tier | Regime | Sizing rule | Gate |
|---|---|---|---|
| $C \le T_1$ | Scarce (near ruin floor) | $x_e = f_{\text{Kelly}}(e)\cdot C$, capped at $\kappa(e)$; hard cap $\le C/2$ | $\theta \approx \theta_0$ (strict) |
| $T_1 < C \le T_2$ | Transition | $x_e = \min(\kappa(e),\ \alpha\,C)$ with $\alpha$ fixed | $\theta$ decreasing per (7.3) |
| $T_2 < C \le T_3$ | Comfortable | $x_e = \min(\kappa(e),\ \bar\kappa)$ (absolute cap) | $\theta \to$ mid-range |
| $C > T_3$ | Abundant | $x_e = \min(\kappa(e),\ \bar\kappa)$, accept all $\mu(e) \ge \theta_\infty$ | $\theta \approx \theta_\infty$ |

Here $\bar\kappa$ is an **absolute per-event cap** (a multiple of the median $\kappa$, e.g.
$\bar\kappa = q_{0.5}(\kappa) \cdot 10 \approx 0.04$), which stabilises the heavy-tailed $\kappa$
and enforces the load condition (6.2). The Kelly fraction $f_{\text{Kelly}}$ is defined in §10.4;
in the scarce tier it is additionally shrunk by the utilisation of the budget to prevent liquidity
starvation.

## 8. Online parameter estimation

All estimates are **empirical-process** plug-ins updated from the observed stream; each is given
with its small-sample correction, because $n = 61$ is tiny and the tails are heavy.

### 8.1 Inter-arrival distribution $\hat F_\Delta$

For arrival slots $\{\tau_i\}$, define gaps $\Delta_i = \tau_i - \tau_{i-1}$ (with $\Delta_1 =
\tau_1 - \tau_0$). The empirical CDF is

$$
\hat F_\Delta(t) \;=\; \frac{1}{n}\sum_{i=1}^{n} \mathbf{1}\{\Delta_i \le t\}, \qquad
\hat{\mathbb{E}}[\Delta] = \bar\Delta = \frac{1}{n}\sum_i \Delta_i \;\approx\; 18. \tag{8.1}
$$

Because the stream is bursty (atom at $\Delta = 0$ from same-slot batches), the raw ECDF is kept
(i.e. **do not** smooth the zero gap); the batch multiplicity is itself an input to the deferral
logic of §7.2.

### 8.2 Commitment-size distribution $\hat F_{\kappa|\nu}$

For each pool $\nu$ with $n_\nu$ observed sizes $\{\kappa_j\}$, shrink the pool estimate toward the
global empirical CDF (Bayesian / James–Stein style, robust for sparse pools):

$$
\hat F_{\kappa|\nu}(x) \;=\; w_\nu\, \hat F_{\kappa|\nu}^{\text{raw}}(x) + (1-w_\nu)\, \hat F_\kappa^{\text{global}}(x),
\qquad w_\nu = \frac{n_\nu}{n_\nu + k}, \tag{8.2}
$$

with $k$ a prior-strength hyperparameter (e.g. $k = 2$). For pools with $n_\nu = 0$ (unseen),
fall back to $\hat F_\kappa^{\text{global}}$. The heavy tail (p95/median $\approx 30\times$)
recommends fitting a **Pareto tail** above the 90th percentile and splicing it onto the empirical
body, which yields a stable estimate of $\mathbb{E}[\kappa]$ used in (6.2).

### 8.3 Return survivor and expected net return

The empirical survivor of the scored return is

$$
\hat S_\rho(r) \;=\; \frac{1}{n}\sum_i \mathbf{1}\{\rho_i > r\}, \qquad
\hat{\mathbb{E}}[\rho] = \bar\rho \approx 0.034, \quad
\hat{\mathbb{E}}[\rho^2] = \frac{1}{n}\sum_i \rho_i^2. \tag{8.3}
$$

The expected **net** return per pool is the shrinkage-corrected combination of (3.3) and (8.3):

$$
\hat\mu_\nu \;=\; \hat q_\nu \big(\bar\rho_\nu - \bar\psi_\nu 10^{-4}\big) - (1-\hat q_\nu)\,\hat\ell_\nu, \tag{8.4}
$$

where $\hat q_\nu$, $\hat\ell_\nu$ are pool-level estimates of the counterparty-arrival probability
and downside (below), and $\bar\rho_\nu$ is the (shrinkage-adjusted) pool mean.

### 8.4 Lock duration and counterparty arrival $\hat F_L, \hat q, \hat\ell$

$L$ and $Z$ are **latent in the scored stream** (the schema reports predicted $\rho$, not realised
outcomes), so they are estimated either (i) from a labelled backfill where counterparty slots are
observed, or (ii) via a prior, then updated. Two ingredients:

* **Lock-duration CDF.** If counterparty arrival times are observed, $L_i$ is the gap from
  commitment to counterparty slot; a Kaplan–Meier estimator is used because $L$ is **right-censored**
  at $L_{\max} = 8$ when no counterparty arrives by the window bound:

$$
\hat F_L(l) \;=\; 1 - \prod_{k \le l} \Big(1 - \frac{d_k}{r_k}\Big), \qquad l \in [1,8], \tag{8.5}
$$

with $d_k$ = arrivals observed at lock $k$ and $r_k$ = risk set at $k$. In the absence of labels, a
uniform prior $\hat F_L(l) = l/8$ (mean 4) is used and updated by (8.5) as labels accrue.

* **Counterparty probability and downside.** With $Z_i \in \{0,1\}$ observed (or imputed), the
  plug-in estimates are

$$
\hat q = \frac{1}{n}\sum_i Z_i, \qquad
\hat\ell = \frac{\sum_i (1-Z_i)\,\ell_i}{\sum_i (1-Z_i)}, \tag{8.6}
$$

with $\ell_i$ the realised fractional adverse-movement loss on unwinds where $Z_i=0$. Until
labels exist, use $\hat q \in (0.7, 0.95)$ and $\hat\ell \approx 0.01$–$0.05$ as a conservative
prior and note that (6.6) is *monotone* in $(1-\hat q)\hat\ell$: under-estimating $\hat q$ or
$\hat\ell$ only makes the policy more conservative.

### 8.5 Derived quantities fed to the policy

$$
c_{\text{opp}} = \frac{\hat{\mathbb{E}}[\rho^\ast]}{\hat{\mathbb{E}}[\Delta]}, \qquad
\theta_{\text{be}} = \frac{c_{\text{opp}}\hat{\mathbb{E}}[L] + (1-\hat q)\hat\ell}{\hat q}, \tag{8.7}
$$

$$
\hat f_{\text{Kelly}} = \frac{\hat q(\bar\rho - \bar\psi10^{-4}) - (1-\hat q)\hat\ell}
{\hat q\,\hat{\mathbb{E}}[\rho^2] + (1-\hat q)\,\hat\ell^2}, \tag{8.8}
$$

with $\hat{\mathbb{E}}[\rho^\ast]$ the mean return of the top accepted decile (the "best available
alternative"), estimated online as the running mean of accepted scores. The concentration penalty
$\beta$ in (7.1) is calibrated by cross-validation over the logged stream (grid $\beta \in
\{0, 10^{-3}, 3\times10^{-3}, 10^{-2}\}$), maximising §9's terminal wealth net of §11's drawdown.

## 9. Simulation procedure

Replay the logged stream against any policy with Monte-Carlo draws of the latent quantities.
Notation: `events` sorted by $\tau$; `active` = multiset of (event, $L$, $\kappa$); `Q` = FIFO of
pending events with deadlines.

```
function evaluate_policy(policy, events, C0, H, rng, n_trials):
    results = []
    for trial in 1..n_trials:
        C        = C0
        active   = {}                       # event -> (kappa, resolve_slot)
        Q        = deque()                  # pending: (event, deadline)
        history  = [(0, C0, C0)]
        for tau in 0..H:
            # 1. Resolve matured commitments: release principal + realised return
            for e in active matured at tau:
                L, kappa = active[e]
                Z = draw_counterparty(e, rng)          # Bernoulli(q(e))
                if Z: R = rho(e) - fee(e)              # success
                else: R = -draw_loss(e, rng)           # adverse movement
                C += kappa * (1 + R)
                active.remove(e)
            # 2. Ingest arrivals at tau and expire stale queue entries
            for e in events with tau_i == tau:
                Q.append((e, tau + delta))
            drop from Q any (e, d) with d < tau
            # 3. Decide (may defer, so iterate to a fixed point)
            while Q not empty and budget_feasible(active, C, C0):
                e, d = Q.head
                s = policy.score(e, C, active, history)
                if s >= theta(C) and C >= kappa(e) and B(active)+kappa(e) <= C0:
                    L = draw_lock(e, rng)              # ~ F_L, capped at L_max
                    x = policy.allocate(e, C, active)  # full or water-filling
                    active[e] = (x, tau + L + 1)
                    C -= x
                    Q.pop()
                elif policy.defer(e, d, tau):
                    break                              # hold head; wait one slot
                else:
                    Q.pop()                            # reject
            history.append((tau, C, W(C, active)))
        results.append((terminal_W, history))
    return aggregate(results)          # mean, quantiles, drawdown, ruin
```

**Correctness notes.** (i) The exposure cap is checked as $B(\text{active}) + \kappa \le C_0$
and feasibility as $C \ge \kappa$, per §3.2. (ii) The reward is realised at
$\tau + L + 1$ and credited to $C$ in step 1, matching (3.2). (iii) `draw_counterparty`,
`draw_lock`, `draw_loss` sample from $\hat q$, $\hat F_L$, $\hat\ell$ of §8.4. (iv) Partial
allocation uses (7.5) inside `policy.allocate`; the binary model returns $\kappa(e)$.

## 10. Baseline policies

All baselines respect the feasibility and exposure constraints of §3.2.

### 10.1 Always-commit
Accept every event at full $\kappa(e)$, subject only to feasibility/exposure. Under bursty
arrivals this violates (6.7) and is expected to underperform; it serves as the upper bound on
*participation* and the lower bound on *selectivity*.

### 10.2 Fixed-fraction
Accept $e$ iff $\kappa(e) \le \alpha\, C(\tau^-)$, for $\alpha \in \{0.1, 0.25, 0.5\}$, committing
the full $\kappa(e)$. This is a pure *size* gate: it ignores return and concentration, and is
included to isolate the value of the return-based signal.

### 10.3 Greedy-$\rho$
Among events sharing the same slot, commit to the single event with the largest $\rho(e)$ (ties
broken by larger $\kappa$), full commitment if feasible. This isolates the value of *ranking* under
a hard concurrency budget.

### 10.4 Kelly-like
Growth-optimal betting: with i.i.d. net-return $R$ (mean $\mu$, second moment $\mathbb{E}[R^2]$),
maximising $\mathbb{E}[\log W]$ gives, to second order,

$$
f^\ast \;=\; \frac{\mu}{\mathbb{E}[R^2]}
\;=\; \frac{q(\bar\rho - \bar\psi10^{-4}) - (1-q)\ell}
{q\,\mathbb{E}[\rho^2] + (1-q)\ell^2}, \tag{10.1}
$$

the plug-in of which is (8.8). The per-event commitment is

$$
x_e \;=\; \min\!\big(\kappa(e),\ f^\ast \cdot C(\tau^-),\ C_0 - B(\tau^-)\big), \tag{10.2}
$$

and the event is accepted iff $\mu(e) > 0$. The brief's form $f = \rho(e)/\mathbb{E}[\rho^2]$ is the
special case of (10.1) with $q = 1$, $\ell = 0$ (no adverse-movement risk) and the individual
$\rho(e)$ substituted for the population mean; (10.1) is the correct de-rated version under the
downside of §3.

## 11. Risk metrics

Define the wealth trajectory $W(\tau) = C(\tau) + B(\tau)$ from a simulation (§9). All metrics are
Monte-Carlo estimators over $n_{\text{trials}}$ trajectories.

### 11.1 Ruin probability

$$
\mathbb{P}_{\text{ruin}} \;=\; \mathbb{P}\!\Big(\inf_{\tau \in [0,H]} C(\tau) < 0.1\, C_0\Big)
\;\approx\; \frac{1}{n_{\text{trials}}} \sum_{t} \mathbf{1}\Big\{\min_\tau C^{(t)}(\tau) < 0.1 C_0\Big\}. \tag{11.1}
$$

The **wealth-ruin** variant (relevant when downside $\ell$ is positive) replaces $C(\tau)$ by
$W(\tau)$.

### 11.2 Expected maximum drawdown

The drawdown of a trajectory is

$$
\text{DD}(t) \;=\; \max_{s \le t} W^{(t)}(s) - W^{(t)}(t), \qquad
\text{MDD} \;=\; \max_{t} \frac{\text{DD}(t)}{C_0}, \tag{11.2}
$$

and the expected maximum drawdown is $\mathbb{E}[\text{MDD}] = \frac{1}{n_{\text{trials}}}\sum_t
\text{MDD}^{(t)}$.

### 11.3 Expected time to target

For $C_{\text{target}} = 10\,C_0$, the first-passage time is

$$
\tau^\ast \;=\; \min\{\tau : W(\tau) \ge C_{\text{target}}\}, \qquad
\mathbb{E}[\tau^\ast] \;\approx\; \frac{1}{n_{\text{trials}}}\sum_t \tau^{\ast(t)}, \tag{11.3}
$$

with $\tau^\ast = +\infty$ (censored at $H$) for trajectories that never hit the target; report
both the conditional mean and the hitting probability $\mathbb{P}(\tau^\ast \le H)$.

**Selection rule.** A policy is admissible if $\mathbb{P}_{\text{ruin}} \le \epsilon_{\text{ruin}}$
(e.g. 5%); among admissible policies choose the one maximising terminal wealth subject to
$\mathbb{E}[\text{MDD}] \le \epsilon_{\text{dd}}$. This makes the "Kelly-like" baseline of §10.4
non-admissible under heavy downside unless $f$ is additionally shrunk, which motivates the
scarce-tier cap of §7.4.

## Appendix A. Quick reference

**Expected net return (per unit).**
$\mu(e) = q(\rho - \psi10^{-4}) - (1-q)\ell$.

**Score.**
$s(e) = \mu(e) - \beta\,\nu(1-\sigma) - \tfrac{\kappa}{C_0}\eta$.

**Gate.**
accept iff $s(e) \ge \theta(C)$, $\theta(C)=\theta_\infty+(\theta_0-\theta_\infty)e^{-C/C_0}$.

**Allocation.**
$x_e = \kappa(e)\big(1-\tfrac{\lambda}{2\rho(e)}\big)_+$, $\lambda=\tfrac{2(\sum\kappa - \bar x)}{\sum \kappa/\rho}$,
$\bar x = \min(C,\ C_0 - B)$.

**Break-even.**
$\theta_{\text{be}} = \tfrac{c_{\text{opp}}\mathbb{E}[L] + (1-q)\ell}{q}$, $c_{\text{opp}} =
\mathbb{E}[\rho^\ast]/\mathbb{E}[\Delta]$.

**Kelly.**
$f^\ast = \tfrac{q(\bar\rho-\bar\psi10^{-4})-(1-q)\ell}{q\mathbb{E}[\rho^2]+(1-q)\ell^2}$.

**Load.**
$\varrho = \tfrac{\lambda_a \mathbb{E}[\kappa]\mathbb{E}[L]}{C_0} \le 1$.
